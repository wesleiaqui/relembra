UM ESPAÇO PARA SE OBSERVAR

Diário de pensamentos ✧

Registre um pensamento automático, examine-o com calma e escolha uma perspectiva mais equilibrada.

Um exercício em cinco movimentos

1. Observe a situação · 2. Nomeie sentimento e pensamento · 3. Separe fatos de suposições · 4. Encontre uma âncora realista · 5. Escolha um pequeno próximo passo.

Este espaço é para reflexão pessoal, não para diagnósticos. Você não precisa se sentir melhor imediatamente.

CONTROLE DOS SEUS DADOS

Backup e restauração

Leve sua biblioteca com você. Seus dados são seus.

↓

Exportar biblioteca

Faça download de um arquivo JSON com links, transcrições, descrições visuais, anotações, categorias, favoritos e registros do diário de pensamentos.

O backup JSON inclui as descrições visuais, mas não os arquivos de imagem. Guarde seus screenshots originais separadamente.
↑

Restaurar backup

Importe um backup do Relembra. O aplicativo mantém as fichas existentes, evita duplicar registros com o mesmo ID e também importa reflexões.

Restaura lotes automaticamente; arquivos de até 25 MB.
🔒
Seus dados são privados

O aplicativo tem login por senha e salva sua biblioteca no banco de dados D1 da sua conta Cloudflare. Não compartilhe sua senha nem arquivos de backup.
